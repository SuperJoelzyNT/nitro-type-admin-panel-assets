# Admin Panel and Creator Lab artwork

Public artwork hosting for SuperJoelzy’s Admin Panel and Creator Lab. This repository contains artwork only, not application source or account data.

- `NT_Admin_Panel_logo.png`: Admin Panel logo.
- `Creator_Lab_logo.png`: supplied Creator Lab crossed-tools badge, uploaded unchanged.

The artwork is not licensed under MIT. See LOGO-LICENSE.md. This is an independent community project, not an official Nitro Type product.

## Perk thumbnails

The 13 `perk-*.png` files are user-supplied Nitro Type perk thumbnails, copied without alteration. Names, dimensions, SHA-256 checksums and the previously used nitrotype.info/Fandom URLs are recorded in PERK-IMAGES.json. Original artwork rights remain with their respective owners; these images are not covered by the code MIT licence. No account data is included.
